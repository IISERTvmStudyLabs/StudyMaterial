## (1) Given a nonempty set $\Omega$, describe the smallest and largest $\sigma$-algebra of subsets of $\Omega$.

### Answer

The **smallest** $\sigma$-algebra on a nonempty set $\Omega$ is

$$
\{\varnothing, \Omega\}.
$$

The **largest** $\sigma$-algebra on $\Omega$ is the power set

$$
\mathcal P(\Omega).
$$

### Why this is true

A $\sigma$-algebra $\mathcal F$ on $\Omega$ must satisfy:

1. $\Omega \in \mathcal F$.
2. If $A \in \mathcal F$, then $A^c \in \mathcal F$.
3. If $A_1, A_2, \dots \in \mathcal F$, then $\bigcup_{n=1}^\infty A_n \in \mathcal F$.

Since $\Omega \in \mathcal F$, by closure under complements we also get $\varnothing = \Omega^c \in \mathcal F$. So every $\sigma$-algebra contains at least these two sets. The collection $\{\varnothing,\Omega\}$ is itself a $\sigma$-algebra, so it is the smallest one.

On the other hand, $\mathcal P(\Omega)$ contains every subset of $\Omega$, so it is automatically closed under complements and arbitrary unions. Hence it is a $\sigma$-algebra, and clearly the largest possible one.

## (2) Given $A \subset \Omega$, describe $\mathcal A(\{A\})$ and $\mathcal F(\{A\})$, the algebra and the $\sigma$-algebra generated by the set $A$.

### Answer

The algebra generated by the single set $A$ is

$$
\mathcal A(\{A\}) = \{\varnothing, A, A^c, \Omega\}.
$$

The $\sigma$-algebra generated by $A$ is the same:

$$
\mathcal F(\{A\}) = \{\varnothing, A, A^c, \Omega\}.
$$

### Explanation

To form the smallest algebra containing $A$, we must include:

- $A$ itself,
- its complement $A^c$,
- the empty set $\varnothing$,
- and the whole space $\Omega$.

These four sets are closed under complements and finite unions, so they form an algebra. They are also closed under countable unions, because any countable union of sets from this family is again one of these four sets. Therefore the generated algebra and generated $\sigma$-algebra coincide.

### Special cases

If $A = \varnothing$ or $A = \Omega$, then the family collapses to the smallest $\sigma$-algebra:

$$
\{\varnothing, \Omega\}.
$$

## (3) Let $\Omega$ be a nonempty set. Define

$$
\mathcal F_0 = \{A \subseteq \Omega \mid \text{either } A \text{ is finite or } A^c \text{ is finite}\}.
$$

Assume that $\{\varnothing\}$ is a finite set. Prove that $\mathcal F_0$ is an algebra. But $\mathcal F_0$ is not a $\sigma$-algebra if $\Omega$ is an infinite set.

### Answer

### Step 1: $\mathcal F_0$ is an algebra

We check the algebra axioms.

#### (i) $\varnothing, \Omega \in \mathcal F_0$

The empty set is finite, and $\Omega^c = \varnothing$ is finite, so $\Omega \in \mathcal F_0$. Thus both $\varnothing$ and $\Omega$ belong to $\mathcal F_0$.

#### (ii) Closed under complements

If $A$ is finite, then $A^c$ is cofinite, so $A^c \in \mathcal F_0$.

If $A^c$ is finite, then $A$ is cofinite, hence $A^c$ is finite, so again $A^c \in \mathcal F_0$.

So $\mathcal F_0$ is closed under complements.

#### (iii) Closed under finite unions

Let $A,B \in \mathcal F_0$. We consider cases.

- If both are finite, then $A \cup B$ is finite.
- If one is cofinite, say $A^c$ is finite, then

	$$
	(A \cup B)^c = A^c \cap B^c \subseteq A^c,
	$$

	so $(A \cup B)^c$ is finite, meaning $A \cup B$ is cofinite.
- If both are cofinite, then their union is cofinite as well.

Hence $\mathcal F_0$ is closed under finite unions.

Therefore $\mathcal F_0$ is an algebra.

### Step 2: $\mathcal F_0$ is not a $\sigma$-algebra when $\Omega$ is infinite

Assume $\Omega$ is infinite. Choose a countably infinite subset $\{x_1,x_2,\dots\} \subseteq \Omega$ consisting of distinct points. Each singleton $\{x_n\}$ is finite, hence belongs to $\mathcal F_0$.

Now consider the countable union

$$
E = \bigcup_{n=1}^\infty \{x_n\} = \{x_1,x_2,\dots\}.
$$

This set is infinite. If $E^c$ were finite, then $E$ would be cofinite, which would force $\Omega$ itself to be countable and would still not make $E$ finite. More importantly, since $\Omega$ is infinite, we can choose the sequence so that $E$ is a proper infinite subset of $\Omega$. Then $E$ is neither finite nor cofinite. Therefore $E \notin \mathcal F_0$.

So $\mathcal F_0$ is not closed under countable unions, hence it is not a $\sigma$-algebra.

## (4) Let $\Omega$ be a nonempty set. Define

$$
\mathcal F_c = \{A \subseteq \Omega \mid \text{either } A \text{ is countable or } A^c \text{ is countable}\}.
$$

Prove that $\mathcal F_c$ is a $\sigma$-algebra.

### Answer

We verify the $\sigma$-algebra axioms.

### (i) $\varnothing$ and $\Omega$ belong to $\mathcal F_c$

- $\varnothing$ is countable.
- $\Omega^c = \varnothing$ is countable, so $\Omega$ is in $\mathcal F_c$.

### (ii) Closed under complements

If $A$ is countable, then $A^c$ is co-countable, so $A^c \in \mathcal F_c$.

If $A^c$ is countable, then $A$ is co-countable, so again $A^c \in \mathcal F_c$.

So $\mathcal F_c$ is closed under complements.

### (iii) Closed under countable unions

Let $A_1, A_2, \dots \in \mathcal F_c$.

There are two cases.

#### Case 1: Each $A_n$ is countable

Then

$$
\bigcup_{n=1}^\infty A_n
$$

is a countable union of countable sets, hence countable. So the union belongs to $\mathcal F_c$.

#### Case 2: Some $A_N$ is co-countable

Then $A_N^c$ is countable. Since

$$
\left(\bigcup_{n=1}^\infty A_n\right)^c = \bigcap_{n=1}^\infty A_n^c \subseteq A_N^c,
$$

the complement of the union is a subset of a countable set, hence countable. Therefore the union is co-countable, and so it belongs to $\mathcal F_c$.

Thus $\mathcal F_c$ is closed under countable unions.

Therefore $\mathcal F_c$ is a $\sigma$-algebra.

## (5) Let $\Omega$ be a nonempty set and let $\mathcal C = \{A_i \mid i \in \mathbb N\}$ be a partition of $\Omega$, that is, $A_i \cap A_j = \varnothing$ for all $i \ne j$ and $\bigcup_{i \ge 1} A_i = \Omega$. Let

$$
\mathcal F = \left\{\bigcup_{j \in J} A_j \mid J \subseteq \mathbb N\right\},
$$

where for $J=\varnothing$, $\bigcup_{j\in J} A_j = \varnothing$. Prove that $\mathcal F$ is a $\sigma$-algebra.

### Answer

We show that $\mathcal F$ satisfies the three $\sigma$-algebra properties.

### (i) $\varnothing$ and $\Omega$ are in $\mathcal F$

- If $J = \varnothing$, then $\bigcup_{j\in J} A_j = \varnothing$.
- If $J = \mathbb N$, then $\bigcup_{j\in J} A_j = \Omega$.

So $\varnothing, \Omega \in \mathcal F$.

### (ii) Closed under complements

Take any $E \in \mathcal F$. Then $E = \bigcup_{j \in J} A_j$ for some $J \subseteq \mathbb N$.

Because the $A_i$ form a partition of $\Omega$,

$$
E^c = \Omega \setminus \bigcup_{j\in J} A_j = \bigcup_{i \notin J} A_i.
$$

Thus $E^c \in \mathcal F$.

### (iii) Closed under countable unions

Let $E_n \in \mathcal F$ for each $n$.
Write

$$
E_n = \bigcup_{j \in J_n} A_j.
$$

Then

$$
\bigcup_{n=1}^\infty E_n = \bigcup_{n=1}^\infty \bigcup_{j\in J_n} A_j = \bigcup_{j \in \bigcup_n J_n} A_j.
$$

Since $\bigcup_n J_n \subseteq \mathbb N$, the right-hand side is again in $\mathcal F$.

Hence $\mathcal F$ is a $\sigma$-algebra.

### Conceptual meaning

This $\sigma$-algebra consists exactly of all unions of partition blocks. So the partition decides which blocks are kept and which are discarded.

## (6) Let $\Omega$ be a nonempty set and $\mathcal F$ be a $\sigma$-algebra on $\Omega$. For $A \subset \Omega$, define

$$
\mathcal F_A = \{B \cap A \mid B \in \mathcal F\}.
$$

Prove that $\mathcal F_A$ is a $\sigma$-algebra on $A$. This is called the trace $\sigma$-algebra of $\mathcal F$ on $A$.

### Answer

We verify the $\sigma$-algebra axioms relative to the space $A$.

### (i) The whole set $A$ and the empty set are in $\mathcal F_A$

- Since $\Omega \in \mathcal F$, we have $\Omega \cap A = A \in \mathcal F_A$.
- Since $\varnothing \in \mathcal F$, we have $\varnothing \cap A = \varnothing \in \mathcal F_A$.

### (ii) Closed under complements in $A$

Take $E \in \mathcal F_A$. Then $E = B \cap A$ for some $B \in \mathcal F$.

The complement of $E$ inside $A$ is

$$
A \setminus E = A \setminus (B \cap A) = A \cap B^c.
$$

Since $B^c \in \mathcal F$, we have $A \cap B^c \in \mathcal F_A$.

### (iii) Closed under countable unions

Let $E_n \in \mathcal F_A$ for each $n$, and write $E_n = B_n \cap A$ with $B_n \in \mathcal F$.

Then

$$
\bigcup_{n=1}^\infty E_n = \bigcup_{n=1}^\infty (B_n \cap A)
= \left(\bigcup_{n=1}^\infty B_n\right) \cap A.
$$

Since $\mathcal F$ is a $\sigma$-algebra, $\bigcup_n B_n \in \mathcal F$. Therefore the union belongs to $\mathcal F_A$.

Hence $\mathcal F_A$ is a $\sigma$-algebra on $A$.

## (7) Consider the semi-algebra $\mathcal S$ of semiclosed intervals in $\mathbb R$ (see Lecture 2). Prove that $\mathcal F(\mathcal S) = \mathcal B$, the Borel $\sigma$-algebra.

### Answer

We prove two inclusions.

### First inclusion: $\mathcal F(\mathcal S) \subseteq \mathcal B$

Every semiclosed interval is a Borel set. For example, if $\mathcal S$ consists of intervals of the form $[a,b)$, then

$$
[a,b) = (-\infty,b) \cap [a,\infty)
$$

and both $(-\infty,b)$ and $[a,\infty)$ are Borel sets. So each element of $\mathcal S$ is Borel, and therefore the $\sigma$-algebra generated by $\mathcal S$ is contained in $\mathcal B$.

### Second inclusion: $\mathcal B \subseteq \mathcal F(\mathcal S)$

It is enough to show that every open interval is in $\mathcal F(\mathcal S)$, because open sets are countable unions of open intervals.

If $a<b$, then

$$
(a,b) = \bigcup_{n=1}^\infty [a+1/n,\, b)
$$

where empty sets may appear for large $n$ if $a+1/n \ge b$.

Each $[a+1/n,b)$ lies in $\mathcal S$, so $(a,b) \in \mathcal F(\mathcal S)$.

Since every open set is a countable union of open intervals, every open set belongs to $\mathcal F(\mathcal S)$. Hence $\mathcal B \subseteq \mathcal F(\mathcal S)$.

Therefore

$$
\mathcal F(\mathcal S) = \mathcal B.
$$

### The key theorem used

The Borel $\sigma$-algebra on $\mathbb R$ is the smallest $\sigma$-algebra containing all open sets. Since open intervals generate all open sets, any $\sigma$-algebra containing all open intervals must contain $\mathcal B$.

## (8) For $\mathcal S$ above, how do we know that $\mathcal A(\mathcal S)$ is not a $\sigma$-algebra?

### Answer

The algebra $\mathcal A(\mathcal S)$ generated by semiclosed intervals consists of finite unions of sets from $\mathcal S$. In particular, every set in $\mathcal A(\mathcal S)$ has only finitely many interval components.

To show it is not a $\sigma$-algebra, we exhibit a countable union of members of $\mathcal A(\mathcal S)$ that is not in $\mathcal A(\mathcal S)$.

Consider the family of intervals

$$
[1,2),\ [2,3),\ [3,4),\ \dots
$$

Each one belongs to $\mathcal S \subseteq \mathcal A(\mathcal S)$, so each is in the algebra. But their countable union is

$$
\bigcup_{n=1}^\infty [n,n+1) = [1,\infty),
$$

and this set cannot be written as a finite union of semiclosed intervals from $\mathcal S$ in the way elements of the algebra are built.

So $\mathcal A(\mathcal S)$ is not closed under countable unions, and therefore it is not a $\sigma$-algebra.

### Short conceptual reason

An algebra only guarantees closure under finite unions. A $\sigma$-algebra requires closure under countable unions, and finite unions are not enough to capture that extra closure.

## (9) Prove that every countable subset of $\mathbb R$ is in $\mathcal B$.

### Answer

Let $E \subseteq \mathbb R$ be countable. Then we can write

$$
E = \{x_1, x_2, x_3, \dots\}
$$

or as a finite set if the sequence stops.

Each singleton $\{x_n\}$ is closed in $\mathbb R$, hence Borel. Indeed,

$$
\{x_n\} = (-\infty, x_n] \cap [x_n, \infty),
$$

and both sets on the right are closed, hence Borel.

Now

$$
E = \bigcup_{n=1}^\infty \{x_n\},
$$

and a countable union of Borel sets is Borel. Therefore $E \in \mathcal B$.

### The theorem used

The Borel $\sigma$-algebra is closed under countable unions. Since singletons are closed sets, and closed sets are Borel, any countable set is Borel.

## (10) Prove that any nonempty open subset of $\mathbb R$ is a countable union of open intervals, in fact disjoint. The same is true for nonempty open sets of $\mathbb R^d$ with intervals replaced by sets of the form $(a_1,b_1) \times \cdots \times (a_d,b_d)$. However, as in $\mathbb R$, they may not be disjoint anymore.

### Answer for $\mathbb R$

Let $U \subseteq \mathbb R$ be nonempty and open.

For each $x \in U$, consider the set of points in $U$ that can be connected to $x$ by an interval staying inside $U$:

$$
I_x = \{y \in U : \text{the interval between } x \text{ and } y \text{ lies in } U\}.
$$

Because $U$ is open, each $I_x$ is an open interval. Two such intervals are either equal or disjoint, so they partition $U$ into disjoint open intervals.

To see that there are only countably many of them, note that every nonempty open interval contains a rational number. Distinct disjoint intervals contain distinct rationals, so the collection is at most countable.

Therefore $U$ is a countable disjoint union of open intervals.

### A more concrete proof

Equivalently, one may define the maximal open interval in $U$ containing each $x \in U$. These maximal intervals are disjoint, open, and their union is exactly $U$.

### Answer for $\mathbb R^d$

Let $U \subseteq \mathbb R^d$ be nonempty and open.

For every $x \in U$, because $U$ is open there exists an open box

$$
(a_1,b_1) \times \cdots \times (a_d,b_d)
$$

such that

$$
x \in (a_1,b_1) \times \cdots \times (a_d,b_d) \subseteq U.
$$

Using rational endpoints and the density of $\mathbb Q$ in $\mathbb R$, we can choose boxes with rational endpoints inside $U$. There are only countably many such boxes, because $\mathbb Q^d$ is countable.

Hence $U$ is a countable union of open boxes.

Unlike the one-dimensional case, these boxes need not be disjoint.

### The theorem used

The density of the rationals says that every open interval contains a rational number. This is what makes the one-dimensional disjoint decomposition countable.

## (11) For the following collections of subsets $\mathcal C_i$, $i=1,2,3$, of $\mathcal P(\mathbb R)$ prove that $\mathcal F(\mathcal C_i) = \mathcal B$.

$$
\mathcal C_1 = \{(-\infty,x) \mid x \in \mathbb R\}
$$

$$
\mathcal C_2 = \{(-\infty,x) \mid x \in \mathbb Q\}
$$

$$
\mathcal C_3 = \{(a,b) \mid a \in \mathbb Q,\ b \in \mathbb Q\}
$$

### Answer

We show that each collection generates the Borel $\sigma$-algebra.

### (a) $\mathcal F(\mathcal C_1) = \mathcal B$

Every set in $\mathcal C_1$ is open, so it is Borel. Hence

$$
\mathcal F(\mathcal C_1) \subseteq \mathcal B.
$$

Now let $(a,b)$ be an open interval. Then

$$
(a,b) = \bigcup_{n=1}^\infty \Big( (-\infty,b) \cap (-\infty,a+1/n)^c \Big).
$$

Each set on the right is in $\sigma(\mathcal C_1)$ because $(-\infty,b)$ and $(-\infty,a+1/n)$ are in $\mathcal C_1$, and $\sigma$-algebras are closed under complements and intersections.

Therefore every open interval is in $\mathcal F(\mathcal C_1)$, so every open set is in $\mathcal F(\mathcal C_1)$, and hence

$$
\mathcal B \subseteq \mathcal F(\mathcal C_1).
$$

Thus $\mathcal F(\mathcal C_1)=\mathcal B$.

### (b) $\mathcal F(\mathcal C_2) = \mathcal B$

Because $\mathbb Q$ is dense in $\mathbb R$, for any real $x$ we have

$$
(-\infty,x) = \bigcup_{q \in \mathbb Q,\ q<x} (-\infty,q).
$$

So every set in $\mathcal C_1$ belongs to $\sigma(\mathcal C_2)$, which gives

$$
\mathcal F(\mathcal C_1) \subseteq \mathcal F(\mathcal C_2).
$$

But from part (a), $\mathcal F(\mathcal C_1)=\mathcal B$. Also $\mathcal C_2 \subseteq \mathcal B$, so $\mathcal F(\mathcal C_2) \subseteq \mathcal B$.

Therefore $\mathcal F(\mathcal C_2)=\mathcal B$.

### (c) $\mathcal F(\mathcal C_3) = \mathcal B$

Each rational open interval is Borel, so

$$
\mathcal F(\mathcal C_3) \subseteq \mathcal B.
$$

Conversely, every open interval $(a,b)$ can be written as a countable union of rational open intervals:

$$
(a,b) = \bigcup_{\substack{q,r \in \mathbb Q \\ a<q<r<b}} (q,r).
$$

Thus every open interval is in $\mathcal F(\mathcal C_3)$, hence every open set is in $\mathcal F(\mathcal C_3)$. Therefore

$$
\mathcal B \subseteq \mathcal F(\mathcal C_3).
$$

So $\mathcal F(\mathcal C_3)=\mathcal B$.

### The key theorem used

The Borel $\sigma$-algebra on $\mathbb R$ is generated by any one of the standard bases for the topology: open rays, open intervals, or open intervals with rational endpoints.

## (12) For the following collections of subsets $\mathcal C_i$, $i=1,\dots,4$, of $\mathcal P(\mathbb R^d)$, $d>1$, prove that $\mathcal F(\mathcal C_i) = \mathcal B$.

$$
\mathcal C_1 = \{(a_1,b_1) \times \cdots \times (a_d,b_d) \mid -\infty \le a_i \le b_i \le \infty,\ 1 \le i \le d\}
$$

$$
\mathcal C_2 = \{(-\infty,x_1) \times \cdots \times (-\infty,x_d) \mid x_i \in \mathbb R,\ 1 \le i \le d\}
$$

$$
\mathcal C_3 = \{(-\infty,x_1) \times \cdots \times (-\infty,x_d) \mid x_i \in \mathbb Q,\ 1 \le i \le d\}
$$

$$
\mathcal C_4 = \{(a_1,b_1) \times \cdots \times (a_d,b_d) \mid -\infty \le a_i \le b_i \le \infty,\ a_i \in \mathbb Q,\ b_i \in \mathbb Q\}
$$

### Answer

We use the fact that the Borel $\sigma$-algebra on $\mathbb R^d$ is generated by open boxes with rational endpoints.

### (a) $\mathcal F(\mathcal C_1) = \mathcal B$

Every open box belongs to $\mathcal C_1$, so the $\sigma$-algebra generated by $\mathcal C_1$ contains all open boxes. Since open boxes generate the topology on $\mathbb R^d$, the generated $\sigma$-algebra contains all open sets, hence contains $\mathcal B$.

Conversely, every element of $\mathcal C_1$ is a Borel set, because it is a finite product of Borel intervals. Therefore $\mathcal F(\mathcal C_1) \subseteq \mathcal B$.

So $\mathcal F(\mathcal C_1)=\mathcal B$.

### (b) $\mathcal F(\mathcal C_2) = \mathcal B$

For each coordinate $i$ and real number $x_i$, we can write

$$
(-\infty,x_i) = \bigcup_{n=1}^\infty (-\infty,q_n)
$$

for rationals $q_n \uparrow x_i$.

Thus the real-endpoint rays in $\mathcal C_2$ are generated from rational-endpoint rays in $\mathcal C_3$, so

$$
\mathcal F(\mathcal C_3) \subseteq \mathcal F(\mathcal C_2).
$$

On the other hand, every set in $\mathcal C_2$ is Borel, so $\mathcal F(\mathcal C_2) \subseteq \mathcal B$.

Since $\mathcal C_2$ is rich enough to generate all open boxes, it follows that $\mathcal F(\mathcal C_2)=\mathcal B$.

### (c) $\mathcal F(\mathcal C_3) = \mathcal B$

The collection $\mathcal C_3$ is countable, and its elements are Borel. Hence $\mathcal F(\mathcal C_3) \subseteq \mathcal B$.

Conversely, because rational points are dense in $\mathbb R^d$, every open box contains a rational box, and every open set is a countable union of rational boxes. Therefore $\mathcal B \subseteq \mathcal F(\mathcal C_3)$.

Thus $\mathcal F(\mathcal C_3)=\mathcal B$.

### (d) $\mathcal F(\mathcal C_4) = \mathcal B$

The family $\mathcal C_4$ consists of boxes with rational endpoints, allowing infinite endpoints as well. These are all Borel, so the generated $\sigma$-algebra is contained in $\mathcal B$.

But rational open boxes already generate all open sets, so $\mathcal B \subseteq \mathcal F(\mathcal C_4)$.

Therefore $\mathcal F(\mathcal C_4)=\mathcal B$.

### The theorem used

In $\mathbb R^d$, the Borel $\sigma$-algebra is generated by open boxes, and the rational boxes form a countable base for the topology.

## (13) If $\mathcal C = \{\{x\} \mid x \in \mathbb R\}$ then prove that $\mathcal F(\mathcal C) = \mathcal F_c$ and $\mathcal F(\mathcal C)$ is properly contained in $\mathcal B$.

### Answer

Here $\mathcal C$ is the collection of all singleton subsets of $\mathbb R$.

We show that the $\sigma$-algebra generated by all singletons is exactly the countable/co-countable $\sigma$-algebra.

### Step 1: Every countable set is in $\mathcal F(\mathcal C)$

Since each singleton $\{x\}$ lies in $\mathcal C$, and $\sigma$-algebras are closed under countable unions, every countable union of singletons belongs to $\mathcal F(\mathcal C)$.

Therefore every countable subset of $\mathbb R$ belongs to $\mathcal F(\mathcal C)$.

### Step 2: Every co-countable set is in $\mathcal F(\mathcal C)$

If $E$ is countable, then $E \in \mathcal F(\mathcal C)$ by Step 1. Since $\mathcal F(\mathcal C)$ is closed under complements, $E^c$ is also in $\mathcal F(\mathcal C)$.

So every co-countable set belongs to $\mathcal F(\mathcal C)$.

Thus

$$
\mathcal F_c \subseteq \mathcal F(\mathcal C).
$$

### Step 3: Nothing else is needed

Let $\mathcal G$ be any $\sigma$-algebra containing all singletons. Then it contains all countable unions of singletons, hence all countable subsets of $\mathbb R$. By closure under complements, it also contains all co-countable sets. So $\mathcal F_c \subseteq \mathcal G$ for every such $\mathcal G$.

Therefore $\mathcal F_c$ is the smallest $\sigma$-algebra containing $\mathcal C$, which means

$$
\mathcal F(\mathcal C) = \mathcal F_c.
$$

### Proper containment in $\mathcal B$

To show $\mathcal F_c \subsetneq \mathcal B$, it is enough to exhibit a Borel set that is neither countable nor co-countable. Any nonempty open interval works, for instance $(0,1)$.

The interval $(0,1)$ is Borel, but it is uncountable and its complement is also uncountable, so it does not lie in $\mathcal F_c$.

Hence $\mathcal F(\mathcal C) = \mathcal F_c$ is properly contained in $\mathcal B$.

### The key theorem used

Any $\sigma$-algebra containing all singletons must contain all countable unions of singletons, and therefore all countable sets. Taking complements gives all co-countable sets.

## (14) Let $\overline{\mathbb R} = \mathbb R \cup \{-\infty\} \cup \{\infty\}$ be the extended real line. The Borel $\sigma$-algebra on $\overline{\mathbb R}$, denoted by $\overline{\mathcal B}$, is defined as the smallest $\sigma$-algebra containing $\mathcal B \cup \{-\infty\} \cup \{\infty\}$. Prove that

$$
\overline{\mathcal B} = \{A \cup B \mid A \in \mathcal B,\ B \subseteq \{-\infty,\infty\}\}.
$$

### Answer

We prove that the right-hand side is a $\sigma$-algebra containing $\mathcal B$ and the two endpoints, and then use minimality.

### Step 1: The displayed family contains $\mathcal B$ and the endpoints

If $A \in \mathcal B$, then taking $B=\varnothing$ gives $A \cup \varnothing = A$.

Also,

$$
\{-\infty\} = \varnothing \cup \{-\infty\}, \qquad
\{\infty\} = \varnothing \cup \{\infty\}.
$$

So the family contains $\mathcal B \cup \{-\infty\} \cup \{\infty\}$.

### Step 2: Closed under complements

Let $E = A \cup B$ with $A \in \mathcal B$ and $B \subseteq \{-\infty,\infty\}$.

There are four cases, depending on whether $-\infty$ and $\infty$ belong to $B$.

- If $B=\varnothing$, then $E^c = A^c \cup \{-\infty,\infty\}$.
- If $B=\{-\infty\}$, then $E^c = A^c \cup \{\infty\}$.
- If $B=\{\infty\}$, then $E^c = A^c \cup \{-\infty\}$.
- If $B=\{-\infty,\infty\}$, then $E^c = A^c$.

In every case, $A^c$ is Borel and the endpoint part is again a subset of $\{-\infty,\infty\}$.

So the family is closed under complements.

### Step 3: Closed under countable unions

If $E_n = A_n \cup B_n$ with $A_n \in \mathcal B$ and $B_n \subseteq \{-\infty,\infty\}$, then

$$
\bigcup_{n=1}^\infty E_n = \left(\bigcup_{n=1}^\infty A_n\right) \cup \left(\bigcup_{n=1}^\infty B_n\right).
$$

The union $\bigcup_n A_n$ is Borel, and $\bigcup_n B_n$ is still a subset of $\{-\infty,\infty\}$.

Hence the family is a $\sigma$-algebra.

### Step 4: Conclude minimality

This $\sigma$-algebra contains $\mathcal B$ together with the two points $\{-\infty,\infty\}$, so it contains the $\sigma$-algebra generated by them. Conversely, any $\sigma$-algebra containing $\mathcal B$ and the endpoints must contain every set of the displayed form.

Therefore

$$
\overline{\mathcal B} = \{A \cup B \mid A \in \mathcal B,\ B \subseteq \{-\infty,\infty\}\}.
$$

## (15) Let $X$ and $Y$ be nonempty sets and $f : X \to Y$ be a given function. If $A \subset Y$, define

$$
f^{-1}(A) = \{x \in X \mid f(x) \in A\},
$$

(even if the inverse function does not exist). If $\mathcal F$ is a $\sigma$-algebra on $Y$ then prove that

$$
\mathcal F_f = \{f^{-1}(A) \mid A \in \mathcal F\}
$$

is a $\sigma$-algebra on $X$.

### Answer

We use the standard properties of inverse images:

$$
f^{-1}(\varnothing)=\varnothing, \qquad f^{-1}(Y)=X,
$$

$$
f^{-1}(A^c) = \big(f^{-1}(A)\big)^c,
$$

and

$$
f^{-1}\left(\bigcup_{n=1}^\infty A_n\right) = \bigcup_{n=1}^\infty f^{-1}(A_n).
$$

Now we check the axioms.

### (i) $\varnothing$ and $X$ belong to $\mathcal F_f$

Since $\varnothing \in \mathcal F$ and $Y \in \mathcal F$,

$$
f^{-1}(\varnothing)=\varnothing, \qquad f^{-1}(Y)=X.
$$

So $\varnothing, X \in \mathcal F_f$.

### (ii) Closed under complements

If $E \in \mathcal F_f$, then $E = f^{-1}(A)$ for some $A \in \mathcal F$. Hence

$$
E^c = \big(f^{-1}(A)\big)^c = f^{-1}(A^c).
$$

Because $A^c \in \mathcal F$, we get $E^c \in \mathcal F_f$.

### (iii) Closed under countable unions

If $E_n = f^{-1}(A_n)$ with $A_n \in \mathcal F$, then

$$
\bigcup_{n=1}^\infty E_n = \bigcup_{n=1}^\infty f^{-1}(A_n)
= f^{-1}\left(\bigcup_{n=1}^\infty A_n\right).
$$

Since $\mathcal F$ is a $\sigma$-algebra, $\bigcup_n A_n \in \mathcal F$, so the union belongs to $\mathcal F_f$.

Therefore $\mathcal F_f$ is a $\sigma$-algebra on $X$.

### The theorem used

Inverse image preserves arbitrary unions, complements, and therefore all $\sigma$-algebra operations.

## (16) The aim of this exercise is to prove that any $\sigma$-algebra is either finite or uncountable.

### (a) Suppose $X$ is a nonempty set and $\mathcal F$ is a $\sigma$-algebra on $X$. If $\mathcal F$ is an infinite set prove that so is $X$.

#### Answer

We prove the contrapositive.

If $X$ is finite, then its power set $\mathcal P(X)$ is finite, because a finite set has only finitely many subsets. Since every $\sigma$-algebra on $X$ is a subset of $\mathcal P(X)$, it must also be finite.

Therefore, if $\mathcal F$ is infinite, then $X$ cannot be finite. Hence $X$ is infinite.

### (b) Suppose $X$ is a countably infinite set and so is $\mathcal F$. Define $f : X \to \mathcal F$ by

$$
f(x) = \bigcap_{x \in A \in \mathcal F} A, \qquad x \in X,
$$

Prove that $f(x)$ is the smallest set in $\mathcal F$ containing $x$.

#### Answer

For a fixed $x \in X$, consider the family of all sets in $\mathcal F$ that contain $x$. Their intersection is exactly $f(x)$.

We must show two things:

1. $f(x) \in \mathcal F$.
2. If $A \in \mathcal F$ and $x \in A$, then $f(x) \subseteq A$.

#### Why $f(x) \in \mathcal F$

Since $\mathcal F$ is countable, the family of sets in $\mathcal F$ containing $x$ is countable. A countable intersection can be rewritten using complements as

$$
\bigcap_{x \in A \in \mathcal F} A = \left(\bigcup_{x \in A \in \mathcal F} A^c\right)^c.
$$

Because $\mathcal F$ is closed under complements and countable unions, the right-hand side lies in $\mathcal F$.

So $f(x) \in \mathcal F$.

#### Why it is the smallest such set

If $A \in \mathcal F$ and $x \in A$, then $A$ is one of the sets being intersected. Therefore the intersection is contained in $A$:

$$
f(x) \subseteq A.
$$

And since $x$ belongs to every set in the intersection, we also have $x \in f(x)$.

Thus $f(x)$ is the smallest member of $\mathcal F$ that contains $x$.

### (c) If $x \in X$, $y \in X$, and $f(x) \cap f(y) \neq \varnothing$, then prove that $f(x)=f(y)$. Conclude that $f(X)$ (which is a subset of $\mathcal F$) is a partition of $X$.

#### Answer

Suppose $f(x) \cap f(y) \neq \varnothing$, and choose $z \in f(x) \cap f(y)$.

Since $f(x)$ is the smallest measurable set containing $x$, and $z \in f(x)$, we know that $f(z) \subseteq f(x)$. Similarly, because $z \in f(y)$, we get $f(z) \subseteq f(y)$.

But also $x \in f(x)$, so by minimality of $f(x)$ among sets containing $x$ and using the fact that $z \in f(x)$, we can reverse the inclusion argument to obtain equality. More simply: two minimal sets in a $\sigma$-algebra containing points from a common intersection must coincide.

Hence

$$
f(x) = f(y).
$$

Therefore distinct sets in $f(X)$ are disjoint. Since every point $x \in X$ belongs to its own set $f(x)$, the union of all sets in $f(X)$ is $X$.

So $f(X)$ is a partition of $X$.

### (d) If $A \in \mathcal F$ then prove that

$$
A = \bigcup_{x \in A} f(x).
$$

#### Answer

Take any $x \in A$. Since $A$ is a measurable set containing $x$, and $f(x)$ is the smallest measurable set containing $x$, we must have

$$
f(x) \subseteq A.
$$

So

$$
\bigcup_{x \in A} f(x) \subseteq A.
$$

Conversely, if $y \in A$, then $y \in f(y)$, and since $y$ is one of the points indexing the union, we get $y \in \bigcup_{x \in A} f(x)$.

Hence

$$
A = \bigcup_{x \in A} f(x).
$$

### (e) If $X$ is an infinite set then prove that $f(X)$ is an infinite subset of $\mathcal F$.

#### Answer

This part is understood in the context of the exercise where $\mathcal F$ is assumed infinite.

If $f(X)$ were finite, then by part (d), every set in $\mathcal F$ would be a union of some subcollection of the finitely many atoms in $f(X)$. That would give only finitely many possible unions, hence only finitely many sets in $\mathcal F$.

But $\mathcal F$ is assumed infinite. Therefore $f(X)$ cannot be finite.

So $f(X)$ is infinite.

### (f) If $X$ is an infinite set and $\mathcal F$ is an infinite set then $\mathcal F$ must be uncountable.

#### Answer

Assume, for contradiction, that $\mathcal F$ is countably infinite.

Then by the construction in parts (b) through (e), the set of atoms $f(X)$ is infinite. But $X$ is countably infinite, so the partition $f(X)$ can have only countably many atoms, and each measurable set is a union of atoms.

Now part (d) says every measurable set is a union of some subcollection of the atoms. If there are infinitely many atoms, then there are at least as many measurable sets as subsets of a countably infinite set of atoms. The power set of a countably infinite set is uncountable.

So $\mathcal F$ cannot be countably infinite. Since we already know from part (a) that an infinite $\mathcal F$ forces $X$ infinite, the only possibility is that $\mathcal F$ is uncountable.

### Final conclusion

Every $\sigma$-algebra is either finite or uncountable.

### Main theorem behind the argument

The atoms of a $\sigma$-algebra form a partition of the space, and every measurable set is a union of atoms. A countably infinite collection of atoms would produce uncountably many unions, so an infinite $\sigma$-algebra cannot remain countable.
